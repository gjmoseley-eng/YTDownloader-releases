YTDownloader Release Notes

What changed in each version, newest first. To update, choose Check for Updates from the YTDownloader menu.

1.2.0

September 29, 2026
What's New
  • Download History: click History (or press Command-Y) to see your last 100 downloads and jump straight to any of them in Finder.
  • Captions: save a video's English captions as an .srt file, embed them in the video, or both. Videos without captions still download normally.
  • Trim: download just part of a video. A preview window lets you step through frame by frame to set the start and end, and the clip is cut exactly there.
  • Help → Release Notes shows what changed in each version.
Fixed
  • Downloads at 1080p and below now use a stream YouTube blocks far less often, so they finish on the first try more often.
  • Cancelling a download now stops it completely and removes the unfinished files.

1.1.1

September 29, 2026
What's New
  • If YouTube blocks a download partway through, YTDownloader now automatically tries again using a different kind of stream, so the download still finishes. These retried downloads top out at 1080p.
Fixed
  • Some downloads stopped partway with “HTTP Error 403” and failed. They now finish on their own.

1.1.0

August 28, 2026
What's New
  • Added a User Manual and FAQ, both in the Help menu.

1.0.9

August 28, 2026
What's New
  • Full playlist support: download an entire playlist, choose specific videos, or grab a single video from a playlist link.
  • Quality selection adapts for playlist and multi-video downloads.
  • Added Back navigation between the video selection and quality screens.
  • Moved “Check for yt-dlp Update” to the bottom of the window.
  • Added Help → Send Feedback, which opens an email filled in with app info and recent log details.
Fixed
  • The window no longer resizes or jumps when moving between screens.
  • Disabled buttons now look dimmed.
  • Audio-only playlist downloads now save as .m4a instead of .webm.

1.0.8

August 28, 2026
What's New
  • A YouTube link you've copied is pasted into the URL field automatically when the app opens.
  • The video title now appears above the format list.
  • The format list stays visible after a download, so you can grab another quality of the same video without fetching it again.
  • Downloading the same video at the same quality twice no longer overwrites the first file.
  • Added a “Reveal in Finder” button after downloads finish.
  • Added a notification when downloads finish, with a quick “Show in Finder” action.
Fixed
  • The log panel no longer flickers between fetching and downloading.

1.0.7

August 28, 2026
What's New

  • Updates always ask before installing. Nothing installs silently in the background.
Fixed
  • Fixed a brief flicker on launch caused by the macOS password AutoFill panel.
